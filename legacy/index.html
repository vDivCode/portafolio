campus-utp — Servidor MCP académico

Proyecto grupal · desarrollé el servidor MCP
Destacado

Un servidor MCP (Model Context Protocol) que conecta el expediente académico de un alumno con la bolsa de prácticas: el modelo ve sus notas y las vacantes abiertas, y le dice a cuál califica y qué le falta. Implementé 9 herramientas (notas, horarios, aulas libres, cruce de vacantes), recursos y prompts, con autenticación OAuth 2.1 (PKCE), transportes HTTP y stdio, y un plugin para Claude y ChatGPT. Desplegado en Render.

MCPTypeScriptNode OAuth 2.1 / PKCEJSON-RPCRender
Probar en vivo Código privado (trabajo grupal)
La demo corre en un plan gratuito: si está dormida, tarda ~50 s en despertar. Si la primera carga falla, reintenta.
